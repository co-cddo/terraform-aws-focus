# Security

## Reporting a vulnerability

The OCTO Observability team is an advocate of responsible vulnerability disclosure.

If you believe you have found a security vulnerability in this repository,
please **do not** raise a public GitHub issue. Instead, report it through
the UK government's vulnerability reporting service:

**[Report a vulnerability](https://vulnerability-reporting.service.security.gov.uk/)**

Please include:
- A description of the vulnerability and where it is located
- Steps to reproduce
- Any relevant screenshots or logs

We will acknowledge your report within 5 working days and aim to resolve
confirmed vulnerabilities within 30 working days.

## Guidelines

When investigating a potential vulnerability, please:
- Make a good-faith effort to avoid disruption to production systems
- Do not access, modify, or delete data belonging to others
- Do not perform high-intensity automated scanning
- Keep the details confidential until we have confirmed a fix
